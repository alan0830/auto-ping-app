## ✨ 特色功能

1. **點開即跑**：開啟 App 即刻自動對指定 IP 啟動持續 Ping，無需每次手動點擊開始。
2. **完整列出手機 IP 與對外 IP**：
   - **📱 手機 IP**：即時偵測並列出手機目前取得的區域網路/本機 IP（自動識別 `Wi-Fi`、`行動數據` 等網路介面），支援專屬一鍵複製。
   - **🌐 對外 IP**：同步查詢並列出手機的公網 IP（對外 IP）。
   - **一鍵重整**：支援單鍵同時重新整理手機 IP 與對外 IP，或點擊任一 IP 直接複製到剪貼簿。
3. **隨時自訂 IP & 間隔**：
   - 預設目標 `8.8.8.8`（可自訂為任意 IP 或網域名稱，如 `192.168.1.1` 或 `google.com`）。
   - 間隔時間可自由調整（預設 1.0 秒）。
4. **記憶功能**：自動記住您最後設定的 IP 與間隔時間，下次開啟 App 自動載入並開始。
5. **即時統計看板**：
   - 發送次數（Sent）
   - 接收成功次數（Recv）
   - 封包遺失率（Loss %）
   - 即時平均延遲（Avg ms）
6. **防休眠常亮開關**：內建「保持螢幕常亮」開關，避免手機待機螢幕關閉時網路進入節能休眠導致測試中斷。
7. **黑底綠字終端介面**：即時自動滾動輸出標準 Linux Ping 回應，啟動時同步印出手機 IP 與對外 IP，支援一鍵清除與一鍵複製日誌。

## 🕹️ 介面按鈕與操作說明

| 按鈕 / 控制元件 | 狀態與說明 |
| :--- | :--- |
| **📱 手機 IP 顯示與複製** | 顯示手機當前取得的本機 IP 與網路連線類型（如 Wi-Fi 或行動數據）。點擊文字或右側「複製」可將純 IP 存入剪貼簿。 |
| **🌐 對外 IP 顯示與重整/複製** | 即時顯示手機在公網上的對外 IP。點擊「重整」可同時重新抓取手機 IP 與對外 IP；點擊「複製」快速存入剪貼簿。 |
| **停止 / 開始按鈕** | • **運行中**：顯示為 **紅色「停止」按鈕**，點擊立即中斷 Ping 測試。<br>• **停止後**：動態切換為 **綠色「開始 Ping」按鈕**，點擊即可隨時再度開跑。 |
| **重啟按鈕** | 修改上方目標 IP 或間隔時間後，點擊「重啟」會立即停止舊測試並套用新設定重新開始，並同步更新手機 IP 與對外 IP。 |
| **保持螢幕常亮** | 預設為勾選狀態，避免手機螢幕變暗待機時，Android 系統將 WiFi 或行動網路轉入節能省電模式導致測試中斷。 |
| **清除按鈕** | 位於終端視窗右上角，點擊可重設發送/接收/丟包率統計數據，並清空目前終端畫面。 |
| **複製按鈕** | 位於終端視窗右上角，一鍵將目前終端累積的所有 Ping 回應紀錄複製到手機剪貼簿。 |
| **狀態指示燈** | 位於頂部標題右側，即時顯示綠色 `● RUNNING`（測試中）或灰色 `○ STOPPED`（已停止）。 |

## 🚀 GitHub Actions 自動打包

本專案已整合 GitHub Actions 工作流程（`.github/workflows/build-apk.yml`），每當程式碼推送到 `main` 分支時，雲端會自動執行：

1. 設定 JDK 17 與 Gradle 8.7。
2. 編譯 Android Debug APK。
3. 自動將編譯完成的 `AutoPing-v1.0.0.apk` 發布到 GitHub Release 供所有人公開下載。
